# Six-minute demo checklist

- [ ] Camera on; explain the user problem in one sentence.
- [ ] Open a prospect and show prior call history.
- [ ] Start a new call for that same prospect.
- [ ] Walk through a transcript-based call and the eight-stage progress.
- [ ] Show one AI extraction with supporting evidence and caller correction.
- [ ] End early once to demonstrate partial-stage preservation.
- [ ] Save the call and show it in history without overwriting the previous call.
- [ ] Explain one design decision: per-call stage state vs consolidated prospect knowledge.
- [ ] Show the Vercel app, Render `/health`, public GitHub repo, and SQL schema.
